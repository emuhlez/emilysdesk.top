emilysdesk.top

A macOS Tahoe desktop that runs in a browser tab — lock screen, wallpaper, menu bar, dock, and real app windows. Built with React 19, Zustand, and Vite. No router, no backend.

Open the desktop · Source on GitHub

What it is

Every "app" is a window component, not a route. Opening Notes doesn't change the URL — it pushes an id into a Zustand store, and the desktop shell renders that app's window on top of the stack. Dragging, resizing, minimizing, and fullscreen are all reimplemented in the browser, because the point is the illusion.

It ships two ways from the same source: as a website, and as an Electron app.

Runtime

index.html paints a lock-screen clock immediately so the first frame is never blank. React mounts behind it and renders its own visually identical LockScreen, which owns the click-to-unlock fade. Desktop is always mounted underneath.

Window geometry — position, size, fullscreen, sidebar width — stays local to each window component. Window lifecycle — what's open, focused, minimized, and in what z-order — lives in app-store.

The three persisted stores all use the same shape: debounce roughly 400ms into localStorage, hydrate through a loadFromStorage() helper on init, and seed new default content without clobbering anything the user has already edited.

Design language

The visual target is macOS Tahoe 26 and Liquid Glass, pulled from Apple's Human Interface Guidelines and WWDC 2025 session 356 rather than from memory. Two rules do most of the work:

  • Glass belongs on controls, not content. Sidebars, toolbars, and button clusters are glass. Message bubbles and photos stay solid.
  • Corners are concentric. An inner radius equals the parent radius minus the inset — a 24px window with a 10px sidebar inset gets a 14px sidebar.

Every icon is a real SF Symbol exported to assets/sf-symbols/ and inlined as raw SVG. Layout is Tailwind; exact radii, fills, and type sizes are inline style tokens in src/constants/window-chrome.ts and src/styles/typography.ts.

How it got built

  1. The shell first. Vite, React, TypeScript, Tailwind. Wallpaper, dock, menu bar, and a window that could be dragged. No routes, ever.
  2. Arc. The first genuinely hard window — tabs, bookmarks, and a proxy so third-party pages could live inside a fake browser inside a fake desktop.
  3. Notes. Established the pattern everything else copies: feature folder, Zustand store, localStorage, unified toolbar.
  4. Photos. A real library, then the first serious Liquid Glass pass — floating inset sidebar, scroll edge effects.
  5. Lock screen and minimize. Splash clock for instant paint; genie-style minimize that captures the window with html-to-image and parks the thumbnail in the dock.
  6. Roblox Studio. Desktop chrome wrapped around a live prototype running in a separate process, with ports pinned so the two dev servers stop fighting.
  7. Messages. The most recent app, and the first built against the WWDC 356 rules from the start.
Constraints that stuck: Zustand only, no React Router, no data-fetching library, no icon set other than SF Symbols. New apps copy Notes rather than inventing a new stack.
